Owner: Person 1 (Frontend & UI/UX)

Next.js + TypeScript + Tailwind CSS app for DealX. This folder is currently empty and will be scaffolded by Person 1 using their dedicated prompt (see the team's DealX Claude Code Prompts doc).

Planned structure:
- `src/app/` — pages (landing page, product detail page)
- `src/components/` — SearchBar, PriceChart, DealIntegrityGauge, AlternativeCard, LiveDemoTrigger
- `src/lib/api.ts` — typed client for the backend REST API, matching `shared/api_schema.json`

Runs on **port 3000** (see root `docker-compose.yml`).
