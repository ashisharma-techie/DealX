# DealX API Reference

Base URL (local dev): `http://localhost:8000`

This is the human-readable companion to [`shared/api_schema.json`](../shared/api_schema.json) — that JSON file is the source of truth; keep this doc in sync with it.

---

### `GET /products/search`
Search for a product by name, or paste a marketplace product URL.

**Query params:** `q` — search text or a product URL.

**Returns:** a list of matching products, each with `id`, `title`, `image`, `price`, `currency`, `retailer`.

---

### `GET /products/{id}`
Full detail for a single product: title, image, current price, retailer, source URL, and specs.

---

### `GET /products/{id}/forecast`
Historical prices plus a 30-day forecast (with confidence bounds), generated by the ai-engine.

---

### `GET /products/{id}/deal-score`
The Deal Integrity Score (0–100) for the product's current price, a label (e.g. "Genuine Deal"), a human-readable reason, and the 30/60/90-day price baselines it was computed from.

---

### `GET /products/{id}/alternatives`
Matching listings for the same product on other marketplaces, with a match-confidence score and condition (new/refurbished/used).

---

### `POST /alerts/subscribe`
Subscribe to price-drop alerts for a product via Telegram or SMS, optionally with a target price threshold.

**Body:** `productId`, `channel` (`telegram` | `sms`), `contact`, optional `targetPrice`.

**Returns:** `subscribed` (boolean), `alertId`.
